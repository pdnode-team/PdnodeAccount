# Pdnode Account
HELLO! A simple, straightforward, and lightweight account system

So, I’ve migrated from Fresh to Go (Pocketbase) and Vue. If you need the previous version, here is the final Fresh-based release: [Old Branch](https://github.com/pdnode-team/PdnodeAccount/tree/old)

## Tech Stack
SOOOOOO I using Pocketbase + Vue + Go
And a community OAuth IDP extension

## How to use?
In most cases, you can simply use it as intended; no additional tutorials are needed.

## Install
I won't go into too much detail here, as this is not a public system and is only for my own use, so I won't provide it.

Simply head to the GitHub Releases page, download the appropriate archive, and extract it to get started. Visit /_/ to customize your configuration (note that SMTP settings are necessity).

## AI
This project makes partial use of Gemini, primarily for 2FA and the Terra Easter egg.

But don't worry—I usually go back and revise the code generated by AI myself.

## Terra
This project is an entry for the Terra competition and contains hidden "Easter eggs." Collect them all to earn a reward! Please use the dedicated login page: https://account.pdnode.com/login/reviewer
